# 🧮 Scientific Calculator

A clean, fully-featured **Scientific Calculator** built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## ✨ Features

- **Two Modes** — Switch between Scientific and Basic at any time
- **Scientific Functions** — sin, cos, tan (and their inverses), log, ln, √, ∛, x², x³, xʸ, ʸ√x, |x|, x!, 1/x, mod, EXP, π, e, Rand
- **Angle Units** — Toggle between DEG and RAD
- **2nd Functions** — Press `2nd` to access inverse/alternate functions
- **Live Preview** — See the result update as you type
- **Calculation History** — Collapsible history panel; click any entry to restore it
- **Keyboard Support** — Full keyboard input (digits, operators, Enter, Backspace, Escape)
- **Responsive Design** — Works on desktop and mobile screens
- **Dark Theme** — Polished dark UI with yellow accent

---

## 🚀 Getting Started

No installation needed. Just open the file in a browser:

```bash
# Clone or download the project, then:
open index.html
```

Or simply double-click `index.html` from your file explorer.

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0–9`, `.` | Enter digits |
| `+`, `-`, `*`, `/` | Operators |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last character |
| `Escape` | Clear all |
| `%` | Percentage |
